# Digital-Activity-Timeline-Checker
Digital Activity Timeline Checker is a Python-based digital forensic and monitoring tool designed to collect and analyze different types of system activities on a Linux machine. The project gathers browser history, file activity, system logs, network connections, and DNS events, then generates a timeline report for investigation and analysis.

## Project Structure

Digital-Activity-Timeline-Checker/
│
├── main.py
├── History.db
└── report.txt

## Features

* Browser history analysis
* DNS activity monitoring
* Network connection tracking
* System log analysis
* Digital activity timeline generation

## Technologies Used

* Python
* SQLite3
* Linux System Logs

## Output

The tool generates a forensic activity report using collected browser and system activity data.
